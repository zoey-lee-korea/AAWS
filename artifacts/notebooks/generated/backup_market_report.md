### 1.2 평가 기준 및 공식 (Specs Criteria)
- **가치 점수 공식 (Value Scoring Formula)**:
  $$\text{Value\_Score} = \frac{\text{RAM\_GB} \times 10 + \frac{\text{SSD\_GB}}{10} + \text{Rating} \times 20}{\frac{\text{Price\_KRW}}{100,000}}$$
- **추천 임계치 (Recommendation Threshold)**: 가치 점수 상위 2개 모델 (Top 2 highest Value_Score models)
- **필수 포함 항목**: ID, Brand, Model, Price, Score, Category

### 3.2 세부 점수 산출 내역 (Detailed Score Calculation)

1. **LP-001 (레노버 아이디어패드 Slim 3 15IAH8)**
   - 분자: $(16 \times 10) + (512 / 10) + (4.7 \times 20) = 160 + 51.2 + 94.0 = 305.2$
   - 분모: $599,000 / 100,000 = 5.99$
   - 가치 점수: $305.2 / 5.99 \approx \mathbf{50.95}$
   - **평가**: 50만 원대의 압도적인 가격 경쟁력과 필수 이상의 스펙(16GB RAM/512GB SSD)으로 단위 가격당 체감 가치 점수가 50.95점으로 가장 높게 산출됨.

2. **LP-002 (LG전자 2026 그램 프로 16)**
   - 분자: $(32 \times 10) + (1024 / 10) + (4.9 \times 20) = 320 + 102.4 + 98.0 = 520.4$
   - 분모: $1,890,000 / 100,000 = 18.9$
   - 가치 점수: $520.4 / 18.9 \approx \mathbf{27.53}$
   - **평가**: 대용량 스펙(32GB/1TB)과 최고 평점(4.9점)을 기록하였으며, 1.19kg 초경량 프리미엄 폼팩터 대비 합리적인 가격 구조로 2위에 랭크됨.

3. **LP-003 (ASUS ROG 제피러스 G14)**
   - 분자: $(32 \times 10) + (1024 / 10) + (4.8 \times 20) = 320 + 102.4 + 96.0 = 518.4$
   - 분모: $2,150,000 / 100,000 = 21.5$
   - 가치 점수: $518.4 / 21.5 \approx \mathbf{24.11}$
   - **평가**: 외장 그래픽(RTX 4060)과 플래그십 프로세서를 갖추어 절대적 하드웨어 파워는 가장 우수하나, 높은 판매 가격으로 인해 가성비 산식 기준으로는 3위를 기록함.
